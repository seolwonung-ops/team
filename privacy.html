PAPS 팀구성 리그관리 개인정보처리방침

이 앱은 체육 수업용 팀 구성 및 리그전 기록 도구입니다. 개발자는 사용자의 데이터를 수집하거나 개발자의 서버로 전송하지 않습니다.

저장되는 데이터

입력한 학급, 선수(익명 코드), 팀, 경기 기록은 사용자의 브라우저에 저장됩니다. 사용자가 구글 드라이브 연결을 선택하면 같은 데이터가 사용자 본인의 구글 드라이브에 PAPS팀리그_데이터.json 파일로 저장됩니다.

구글 권한 사용

앱은 drive.file 권한만 요청하며, 이 앱이 만든 파일에만 접근합니다. 사용자의 다른 드라이브 파일이나 개인 정보는 읽지 않습니다. 이 데이터는 동기화 기능 제공 목적으로만 사용되며 제3자에게 제공되거나 광고에 쓰이지 않습니다.

삭제

앱의 연결 해제 버튼을 누르거나 구글 계정 설정에서 앱 접근 권한을 취소하면 연동이 끝나며, 드라이브의 JSON 파일은 사용자가 직접 삭제할 수 있습니다.
